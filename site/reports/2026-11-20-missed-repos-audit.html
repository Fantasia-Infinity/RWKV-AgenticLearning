二、内容核验（README/结果原文）

1. rwkv-harbor-scratch：Terminal-Bench 2.0 唯一公开跑分（数字属实）

docs/results/README.md 原文（被测 rwkv7-g1k-7.2b-20260930-ctx25600 + rwkv_lightning_cuda on W7900， agent RwkvTerminus = terminus-2 + 续写后端，Docker x86 模拟 on Apple Silicon，2026-10-28）：

题集 得分
hello-world 1/1
Terminal-Bench 2.0 简单题 0/4
terminal-bench-sample@2.0 0/8（有效 8/10；剔除判分环境损坏的 qemu-alpine-ssh、qemu-startup）

失败分析（原文）：自发 <think> 复读写满输出上限；失败命令照抄/打转（fix-git 同一命令执行 52 次）； 偏离目标/违反约束；简单题上下文仅 10k–24k → 问题在多步决策，不在接入；调采样参数无效。 → 这是目前唯一公开的 RWKV agent 绝对跑分，且是 0 分区间；7.2B + W7900 的配置也不能直接与我们的 1.5B/bf16 对比。

2. rwkv-skills：六域评测脚手架（属实）

README 原文：目标外部 vLLM-RWKV OpenAI 接口；src/eval/tasks/ 含 knowledge / maths / coding / instruction_following / function_calling / agent_bench 六域； GPU scheduler + PostgreSQL；"公开榜在 Helicopter 仓库单独维护" ✅

3. RWKV-RL-Search-R1：唯一公开 agentic RL 数字（属实）

README 表格：GRPO ≈0.40、Dr.GRPO 0.40、RAFT 第一轮 0.407（target 0.45 未达）； 另有 Search-R1 7B Base PPO 0.431 的参考行。训练管线：SFT warm start → GRPO → RAFT/DAPO 取舍。 → 与我们的结论一致：RL 有实现，但公开可比的 agentic RL 数字极少。

4. rwkv_lightning_grpo：state-only 在线 GRPO（属实）

README：Online State-only GRPO；Rollout → 远程 Qwen Judge → GRPO/Dr.GRPO → BPTT → 只更新 FP32 Initial WKV State； 冻结的 BF16 backbone/embedding/head 不拷贝、不保存（全参数梯度图不跨 24 层）。Apache-2.0。

5. RWKV-AUTODECO：15 分钟起训（属实）

README："start pre-training a fully aligned RWKV v7 model within 15 minutes"（191M–3B）， 实际是 RWKV-LM-V7 fork（Lightning 框架）。Apache-2.0。

6. rwkv_lightning_xdna / QueQiao-Router（属实）

  • xdna：C++17 → XRT → amdxdna → NPU 的 Ryzen AI NPU 后端（Apache-2.0）
  • QueQiao-Router：Rust/Axum/Tokio，统一 OpenAI/Azure/Anthropic/DeepSeek/vLLM/Llama.cpp 后端、权重路由/故障转移、 思考格式归一化、Prometheus、按月审计（Apache-2.0，★57）
