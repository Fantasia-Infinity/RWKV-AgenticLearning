RWKV 生态核验报告（2026-11-05 接续 session）

任务：接续 内部交接 2026-11-05（未公开存档） 的「生态核验 / 跟踪」线，复核交接中的未验证项与事实、产出可引用的 delta。 方法：3 名 teammate 并行深挖（reports/skyrl/、reports/state/、reports/eco/）+ Lead 抽验承重事实。 证据：每个结论都可在同目录报告 / reports/*/evidence/ / tracking/runs/ 中回查；时间均为 2026-11-05（CET/UTC 标注）。 公开版政策：第三方全文/HTML/ATOM 已移除，保留报告 + 命令输出 + 结构化数据；被移除原件以 sha256 记录（reports/EVIDENCE.md）。 GitHub API 用量：全队合计 2 次（60/h 限额内的 3%）；其余全部走零配额路径（git ls-remote / commits.atom / raw.githubusercontent.com / org HTML embedded JSON / HF API）。

0. 一句话结论（相对交接的 delta）

交接的核心判断「单轮 RLVR 成熟、多轮 agentic RL 是空白」仍然成立，但它的三条支撑事实需要大幅修订： 1. 生态图严重不全：rwkv-rs 组织实为 40 个公开仓库，交接完全未提 30 个 —— 漏掉的是整层（verl 原生 RL 集成、torchtitan 训练栈、评测生产体系、量化、Rust 全栈）。 2. 「没有模型、没有评测成绩」已被部分推翻：生态外 No-22-Github/RWKV-Agent 有公开 568 题多步 agent 考卷 + 公开跑分（G1l 基模 187/568=32.9%，NoRA 适配器 320.5/568=56.4%）；rwkv-rs/browsecomp-plus-eval 是 830 题 BrowseComp-Plus 的完整评测复现包（无分数）。 3. 「官方主动不做 agentic」的表述已过时：G1l（2026-10-31）官方 chat template 已支持 tool-call/multi-turn，官方文档与 README 主动指向 agent 目录 —— 准确说法是「官方不做 agentic RL 训练，但已把 agentic 接口官方化、把实践外包给社区」。

仍然为真的空白：公开的多轮 agentic RL 训练配方与结果（现有 agent 模型全是 SFT/NoRA/MiSS 适配器，不是 RL）；标准 benchmark（BrowseComp-Plus 830 / τ-bench / BFCL）的 RWKV 公开分数；state-native 多轮 rollout 层。

交接文档里 6 处事实错误已定位并修正（§10.1 五项全部有裁定，见 §1/§2）；剩余真正未验证的只有「真机 8 卡跑通」与「28B 长跑/收敛」两项。

4. 更新后的结论（建议直接替换交接 §0/§5）

4.1 §0 建议版本

RWKV 的单轮 RLVR 已成熟且有官方组织（DAPO 配方、skyrl-rwkv、异步 RLVR 基建）； 多轮 agentic RL 训练仍是公开空白（无公开配方、无公开训练结果、state-native rollout 层仍需自建）。 但 agentic 能力/评测本身已不再空白：官方 G1l（2026-10-31）已官方化 tool-call/multi-turn 提示接口并把 agentic 实践入口指向社区； 社区已有公开的 568 题多步 agent 考卷与跑分（No-22：G1l 基模 32.9% → NoRA 适配器 56.4%）、830 题 BrowseComp-Plus 评测复现包（无分数）。 因此工作量重心从"从零建评测"下调为"接公开评测 + 自建多轮 rollout/RL"。

4.2 §5 建议版本

把"评测层：有框架，几乎没成绩"改为：

评测已工业化（lm-eval/lighteval/evalscope 三个 fork + scoreboard 发布管线 + 16 benchmark 计划，其中 agentic = [] 为空类目）， 但公开的标准 agentic 成绩仍缺；唯一公开的 agentic 成绩来自生态外自建 568 题考卷（No-22，无许可证）。

4.3 §9 路线图影响（最小改动）

  • P0（自建 32 题评测）：可复用 No-22 的 568 题考卷格式 + browsecomp-plus-eval 的 agent loop，把 3 周压缩；
  • P2（单轮 RLVR）：不变，仍用 skyrl-rwkv + DAPO；但可参考 verl-rwkv 的 rwkv_lm engine 设计；
  • P3（多轮 rollout）：不变，仍是生态空白；heli 分支只覆盖"训练→评测回调"，不是 rollout 层。
  • 新增跟踪项：torchtitan-rwkv（训练栈）、Megatrwkv-Bridge（Megatron 桥）、any2rwkv（架构转换）、G1l 之后的官方 tool-call 生态。
