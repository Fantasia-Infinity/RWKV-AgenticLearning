Evidence policy & citations

This directory contains only evidence that can be redistributed: command outputs produced by this project, structured metadata (TSV/JSON), and short quotations needed to support the findings.

What is not published here (and why):

  • Full copies of third-party READMEs, model cards, HTML pages and commit feeds are not redistributed; they remain the property of their authors and are kept only in a private archive on the maintainer's machine.
  • Every removed file is listed in ARCHIVED.tsv with its path, size and sha256 so anyone can re-fetch the original from the cited URL and verify it byte-for-byte.
  • Full-text reproduction is unnecessary for verification and would raise copyright questions, especially for sources without a license.

Re-fetch examples:

# last commit time of a repo
curl -s https://github.com/rwkv-rs/skyrl-rwkv/commits/main.atom | head
# raw README (compare sha256 with ARCHIVED.tsv)
curl -sL https://raw.githubusercontent.com/xiaol/wkvm/main/README.md | sha256sum
