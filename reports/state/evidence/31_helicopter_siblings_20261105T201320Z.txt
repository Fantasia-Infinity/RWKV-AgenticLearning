     1	# BrowseComp-Plus RWKV evaluation package
     2	
     3	This directory is a self-contained source package for reproducing the current
     4	BrowseComp-Plus evaluation path with RWKV-vLLM and the parallel-candidate
     5	router. It is a physical extraction: the evaluator and vendored vLLM sources
     6	are copied into this directory and do not import files from the parent checkout.
     7	
     8	The package does not contain credentials, database rows, model weights, the
     9	official 2+ GB corpus, BM25 index, qrels, or generated scores. Creating and
    10	testing the package does not start vLLM, contact an inference endpoint, connect
    11	to PostgreSQL, use a GPU, or mutate any scheduler/runner state.
    12	
    13	## Runtime flow
    14	
    15	```text
    16	830 official questions
    17	        |
    18	        v
    19	BrowseComp-Plus agent loop -- search(top 5) / get_document / final_answer
    20	        |
    21	        v
    22	3 parallel candidate shards -- evidence/context/tool grounding
    23	        |
    24	        v
    25	candidate aggregation -- one grounded tool call or final answer
    26	        |
    27	        v
    28	OpenAI-compatible /v1/completions -- vendored RWKV-vLLM
    29	        |
    30	        v
    31	PostgreSQL completion/audit rows -- export 830 per-query official run files
    32	        |
    33	        v
    34	internal judge and/or upstream official judge -- accuracy + retrieval Recall
    35	```
    36	
    37	Important implementation entry points:
    38	
    39	- `src/eval/tasks/function_calling/browsecomp_plus.py`: dataset adapter,
    40	  BM25 tools, prompt budgeting, agent loop, evidence persistence, final-answer
    41	  conversion, judge modes, and score payload.
    42	- `src/eval/experiments/parallel_candidate_router/router.py`: candidate shard
    43	  generation, parsing, grounding, deduplication, and aggregation.
    44	- `src/eval/tasks/function_calling/runner.py`: unified CLI and DB lifecycle.
    45	- `src/infer/backend.py`: OpenAI-compatible completion client.
    46	- `vendor/vllm-rwkv/`: exact vendored inference runtime source snapshot.
    47	
    48	## 1. Install
    49	
    50	Python 3.12, PostgreSQL, a CUDA environment compatible with the selected vLLM
    51	build, and Java/pyserini for the BM25 index are required.
    52	
    53	Create the evaluation environment:
    54	
    55	```bash
    56	uv sync --extra dev --extra function-calling-official
    57	cp .env.example .env
    58	```
    59	
    60	Keep vLLM in a separate environment because its CUDA/PyTorch dependency set is
    61	usually stricter than the evaluation harness:
    62	
    63	```bash
    64	uv venv .venv-vllm --python 3.12
    65	uv pip install --python .venv-vllm/bin/python -e vendor/vllm-rwkv
    66	```
    67	
    68	The launch wrapper also prepends the vendored tree to `PYTHONPATH`, ensuring the
    69	copied implementation is selected. It sets `VLLM_USE_V2_MODEL_RUNNER=1`, which
    70	is required by this RWKV7 runtime path.
    71	
    72	## 2. Prepare official assets
    73	
    74	Obtain the official `texttron/BrowseComp-Plus` assets and point
    75	`BROWSECOMP_PLUS_ROOT` at them. The expected layout is documented in
    76	`data/README.md`.
