     1	# RWKV Skills
     2	
     3	English | [中文](README.zh-CN.md)
     4	
     5	An evaluation scaffold for RWKV7 that targets an external vLLM-RWKV OpenAI-compatible inference service, with dataset preppers for common benchmarks and a GPU scheduler skeleton.
     6	
     7	## Project structure
     8	The frontend (`client/`) and backend (`src/`) are strictly separated; third-party benchmark data and evaluation artifacts stay out of the source package.
     9	
    10	- `client/`: dashboard frontend (Next.js + React); `/api/*` is proxied to the FastAPI backend by Next rewrites.
    11	- `src/`: backend Python package
    12	  - `src/eval/tasks/`: per-domain evaluation runners/pipelines — `knowledge`, `maths`, `coding`, `instruction_following`, `function_calling`, `agent_bench`.
    13	  - `src/eval/scheduler`: CLI for queueing eval jobs, GPU/remote-worker detection, and dispatch.
    14	  - `src/eval/datasets`: data structures, JSONL loaders, and per-dataset preppers.
    15	  - `src/eval/{evaluating,evaluators,metrics,results,checkers}`: evaluation engine and metric/result handling.
    16	  - `src/infer`: remote OpenAI/vLLM inference client, sampling configuration, and constraints.
    17	  - `src/dashboard/{web,core}`: dashboard backend (FastAPI web layer + framework-agnostic core logic).
    18	  - `src/db`: PostgreSQL data layer.
    19	  - `src/plugins/lexical_chunk_router`: lexical chunking / tool-routing plugin.
    20	  - `src/bin`: console-script entry points registered in pyproject (infer server/fleet/router, dashboard, perf, download-weights).
