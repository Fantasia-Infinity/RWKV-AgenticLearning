0. 一句话结论

交接最大的系统性缺口不在"skyrl 之外没有 RL"，而在"rwkv-rs 组织级工程化已经跑起来、且 agentic 评测/Agent-SFT 已有公开资产"：rwkv-rs 组织实际有 40 个公开仓库（交接完全未提其中 30 个）；verl-rwkv 是比 skyrl-rwkv 早 3 个月的真实 verl native RWKV 集成（43 个 RWKV 文件、18 个 PR，但 2026-08-02 起停更）；browsecomp-plus-eval 是 830 题 BrowseComp-Plus 的完整 RWKV agent 评测复现包（无公开分数、无 LICENSE）；生态外 No-22-Github/RWKV-Agent 已有公开 568 题多步 agent 考卷 + 公开跑分（官方 G1l 基模 187/568 = 32.9%，NoRA 适配器 320.5/568 = 56.4%）。同时 2026-10-31 官方 G1l 发布 + 11-04 官方文档更新后，"官方主动不做 agentic"已不能原样引用：官方 chat template 已支持 tool-call、官方模板与模型卡已明确给出 agentic 入口。仍然成立的是：官方与社区都没有公开的"多轮 agentic RL 训练"配方与结果（agent 能力目前靠 SFT/适配器 + 自建评测）。
